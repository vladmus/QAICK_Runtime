## QAICK foundational principles

Before substantial QAICK design, implementation, QA, UX, AI or release reasoning, read the [canonical QAICK principles index](https://github.com/vladmus/QAICK_Design/blob/main/PRINCIPLES.md) and the relevant linked original sources. In particular, apply Musienko's Razor (“If your logic is complicated, it's probably wrong.”), question-first reasoning, evidence neutrality, and epistemic honesty. Do not assume repository presence means a source was actually retrieved. This link is a discovery rule, not permission to change scope, code, contracts or releases.

For repository-specific behavior, consult this repository's README and the current QAICK_Design governance/Contract records. Preserve previously approved role boundaries.
